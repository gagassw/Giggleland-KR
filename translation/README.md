# translation/ — 번역 데이터 (저장소에는 없음)

여기에는 한국어 번역 데이터가 들어갈 자리다. 하지만 **이 저장소에는 번역문도, 게임 원문도 두지 않는다.**

## 왜 저장소에 없나

- **저작권**: 게임의 영어 원문과 그 번역문은 게임 저작물에서 파생된다. 공개 저장소에 올리지 않는다.
- **스포일러**: Giggleland 은 심리공포 게임이다. 대사·자막을 그대로 공개하면 스토리가 노출된다.
- **투명성과의 양립**: 패치본 `resources.assets` 를 열어 무엇이 바뀌는지 직접 검증할 수 있다(바뀌는 것은 번역 텍스트와 폰트뿐). 번역문을 저장소에 공개하지 않아도 확인 가능하다. ([`SECURITY.md`](../SECURITY.md))

## 번역은 어디에

완성된 번역은 **GitHub Releases 로 배포되는 패치본 `resources.assets`** 안에 직접 반영돼 있다(게임의 `LocalizationData` 각 항목의 `en` 값을 한국어로 교체). 원리는 [`docs/HOW_IT_WORKS_KO.md`](../docs/HOW_IT_WORKS_KO.md).

## 직접 만들어 보고 싶다면
